# Big Agent — 自我进化的 AI 智能体

## 核心理念

一个**能自学、能自改、能自愈的 AI 智能体**，以 PC 技能 mastery 为进化方向。

- **学习**：自己上网搜索新技术 → 筛选有用信息 → 理解原理 → 记住做法
- **记忆**：RAG 方式存储，成功案例可参考，失败案例要分析原因
- **进化**：学会新技能后，能改自己代码来集成，通过 git 保障安全
- **服务**：用户通过 Web UI / 桌面窗口发起指令，高效响应

## PC 技能进化路线图

技能按难度分级，agent 逐步掌握：

| 级别 | 技能 | 说明 |
|------|------|------|
| L1 | 文件/应用操作 | 打开软件、文件读写、基本系统操作  |
| L2 | 桌面自动化 | 鼠标键盘、窗口管理、截图 OCR |
| L3 | **网络爬虫** | 理解网页、抓取数据、API 交互 |
| L4 | **文档处理** | Word/PPT/PDF/Excel 生成和编辑 |
| L5 | 跨应用自动化链条 | 多步骤复杂流程 |
| L6 | 复杂问题解决 | 分析问题 → 搜方案 → 执行 |

当前状态: L1-L2 ✅ (部分)  /  L3-L6 ⬜ (待学习)

## 关键设计原则

1. **先筛选再学习** — 网络信息 90% 是噪音，必须 LLM 过滤
2. **理解 WHY 比 HOW 重要** — 不只要知道怎么做，要理解为什么这么做
3. **失败比成功更有价值** — 每次失败都要分析原因，存入记忆
4. **git 保障安全** — 改代码前先 commit，坏了能回滚
5. **模型是工具不是大脑** — 换模型只需改配置，核心能力在自身架构
