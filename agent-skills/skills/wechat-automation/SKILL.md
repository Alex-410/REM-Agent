# wechat-automation

## Overview

wechat-automation 是一种利用桌面 GUI 自动化技术（如 PyAutoGUI、SikuliX 或 AutoHotkey）来模拟用户操作微信客户端的技术方案。它能够在不依赖微信官方 API 的情况下，自动完成发送消息、发送文件、管理群聊等常见任务，适用于需要批量操作或定时任务的场景。

## When to Use

- 需要定时或批量向微信联系人发送消息或文件。
- 需要自动化管理群聊，如发送群公告、踢人、设置群名。
- 微信官方未提供开放 API，或使用 Web 版受限时。
- 用户已安装微信桌面客户端，且允许自动化脚本模拟鼠标键盘操作。

## Process

1. **环境准备**  
   - 安装微信桌面客户端（Windows/macOS）。  
   - 安装 GUI 自动化库（如 Python 的 `pyautogui`、`uiautomation` 或 `pywinauto`）。  
   - 确保屏幕分辨率和缩放比例固定，以便定位元素。

2. **定位关键元素**  
   - 使用截图工具获取搜索框、聊天窗口、发送按钮等位置的坐标。  
   - 或利用图像识别（如 `pyautogui.locateOnScreen`）动态定位。

3. **编写自动化脚本**  
   - 打开微信客户端并确保已登录。  
   - 搜索联系人/群聊：模拟鼠标点击搜索框，输入名称，确认。  
   - 发送消息：在输入框键入内容，点击发送按钮。  
   - 发送文件：点击附件按钮，选择文件。  
   - 群聊管理：根据需求模拟右键菜单操作或界面按钮。

4. **调度与异常处理**  
   - 使用定时任务（如 cron、Windows 任务计划程序）按需执行。  
   - 添加错误捕获与重试逻辑，应对窗口未激活或未找到元素的情况。

## Verification

- 运行脚本后，检查微信客户端是否按预期执行操作（如消息已发送、文件已传输）。  
- 验证日志：记录每次操作的时间、对象、结果，对比预期与实际。  
- 边缘情况测试：微信窗口最小化、被遮挡、未登录等场景下脚本是否能正确处理。  
- 稳定性测试：连续执行多次操作，确认无累积错误或系统资源泄漏。
