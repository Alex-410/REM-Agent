# file-organization

## Overview

文件整理技能涉及对计算机文件系统进行系统化的组织、清理和转换操作。通过脚本化或手动方式，实现文件的批量重命名、按规则分类归档、格式统一转换（如图片、文档、音频格式互换）以及临时文件的批量删除。该技能可大幅提升文件管理效率，减少手动重复劳动，并保持目录结构的清晰与一致性。

## When to Use

- 下载文件夹杂乱无章，需要按类型或日期归档。
- 有大量文件需要按照特定命名规则（如添加日期、序列号）进行批量重命名。
- 需要将一批文件从一种格式转换为另一种格式（如 .jpg → .png，.docx → .pdf）。
- 系统或应用程序残留大量临时文件（如 .tmp、.log、.bak），需要安全清理以释放空间。
- 定期维护工作目录，保持其结构化，便于后续查找和自动化处理。
- 在进行数据迁移或备份前，统一文件命名和目录结构。

## Process

1. **评估与规划**
   - 确定整理目标（按类型、日期、项目、关键词等）。
   - 分析当前文件分布，识别需要归档、重命名、转换或清理的文件。
   - 制定命名模板和分类规则（例如：`YYYY-MM-DD_项目名_序号`）。

2. **备份与安全**
   - 对重要数据先备份，防止误操作。
   - 使用测试副本或 `--dry-run` 模式预览操作结果。

3. **批量重命名**
   - 使用工具（如 `rename`、`PowerShell`、`Bulk Rename Utility`）或脚本（Python `os.rename`）执行。
   - 应用规则：添加前缀/后缀、替换特定字符、统一大小写、插入日期或序号。
   - 示例命令：`rename 's/old/new/' *.txt`

4. **分类归档**
   - 创建目标文件夹（如 `Images/`, `Documents/`, `2024/`）。
   - 按文件扩展名、创建日期或关键词移动文件：`mv *.jpg ./Images/`
   - 使用脚本扫描子目录并移动符合条件的文件。

5. **格式转换**
   - 选择转换工具（如 `ffmpeg` 用于媒体文件，`pandoc` 用于文档，`magick` 用于图片）。
   - 编写循环批量处理：`for f in *.mp3; do ffmpeg -i "$f" "${f%.mp3}.wav"; done`
   - 注意参数调整（质量、压缩率、分辨率）。

6. **清理临时文件**
   - 识别临时目录（如 `/tmp`、`%TEMP%`、缓存文件夹）。
   - 使用 `find`、`rm`、`del /s` 或专用清理工具（如 `bleachbit`）。
   - 谨慎操作，避免删除正在使用的文件。建议先列出再删除。

7. **验证与维护**
   - 检查整理后目录结构是否符合预期。
   - 确认重命名、转换、清理操作无错误。
   - 记录整理规则，形成可重复执行的脚本或配置。

## Verification

- **重命名验证**：随机采样若干文件，检查命名规则是否正确应用，文件未丢失或损坏。
- **归档验证**：确认所有应移动的文件已进入正确文件夹，原位置无残留，且无重复副本。
- **转换验证**：检查转换后文件的格式、分辨率、元数据；播放或打开部分文件确保可访问。
- **清理验证**：确认临时目录已清空或按预期删除了指定类型文件，系统/应用无异常报错。
- **完整性检验**：比较整理前后的文件总数（排除删除项），确保无意外丢失。
- **可逆性检查**：若使用了重命名或移动操作，确保保留日志或备份以便回滚。
