# system-maintenance

## Overview

系统维护是确保操作系统稳定、高效和安全运行的重要技能。该技能涵盖磁盘空间清理、进程管理与监控、启动项管理以及系统信息收集等核心任务。通过定期执行这些维护操作，可以预防性能下降、资源耗尽和潜在的安全风险，延长系统使用寿命。

## When to Use

- 系统运行缓慢或响应迟钝时
- 磁盘空间不足或临时文件堆积
- 需要排查异常进程或高资源占用
- 系统启动速度变慢或存在不必要的自启动项
- 进行系统审计、故障诊断或性能基准评估前
- 定期维护窗口（例如每周或每月）

## Process

1. **收集系统信息**  
   - 检查操作系统版本、内核信息、内存、CPU、磁盘分区和网络配置。  
   - 使用工具如 `uname -a`, `df -h`, `free -m`, `lscpu`, `ip addr` 或 `systeminfo`（Windows）。

2. **进程管理**  
   - 列出所有运行中的进程（`ps aux` 或任务管理器）。  
   - 识别高 CPU/内存占用进程，分析其必要性。  
   - 结束异常或无用进程（`kill` 或任务管理器结束任务）。  

3. **磁盘清理**  
   - 分析磁盘使用情况（`du -sh /*`, `ncdu`, `Disk Cleanup`）。  
   - 清理临时文件（`/tmp`, `%TEMP%`, 浏览器缓存）。  
   - 卸载不再使用的软件，清除包管理器缓存（`apt clean`, `yum clean all`）。  
   - 使用 `fsck` 或 `chkdsk` 检查并修复文件系统错误。

4. **启动项管理**  
   - 列出系统服务与自启动程序（`systemctl list-unit-files`, `msconfig` 或任务管理器启动页）。  
   - 禁用不需要的启动项，包括过时驱动、不必要的后台服务。  
   - 审核计划任务（`crontab -l`, `schtasks`）。

5. **验证与收尾**  
   - 检查维护前后的性能指标（响应时间、磁盘空间、进程数量）。  
   - 确保关键服务正常运行。  
   - 记录变更，以便回滚或后续审计。

## Verification

- 确认磁盘可用空间增加（运行 `df -h` 或磁盘属性）。  
- 使用 `top` / `htop` 或任务管理器验证异常进程已被清理。  
- 重启系统并观察启动速度是否有改善。  
- 执行一次完整的系统信息收集，与维护前对比，确认各项指标正常。  
- 检查系统日志（`/var/log/syslog`, `Event Viewer`）确认无新增错误。
