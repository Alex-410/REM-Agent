# Data Analysis

## Overview

数据分析是检查、清理、转换和解释数据以发现有意义的模式、趋势和洞察的过程。它通过将原始数据转化为可操作的信息，帮助组织在业务、医疗、金融和科学研究等领域做出更明智的决策。有效的数据分析依赖于明确的目标、高质量的数据以及对适当工具和技术（如数据透视表、统计模型和可视化）的合理使用。

## When to Use

- 当需要基于证据而非直觉做出决策时（例如：优化运营、改进产品、理解客户行为）。
- 在识别趋势、异常或关联性以驱动战略规划时。
- 在评估过去表现或预测未来结果时（如销售预测、资源分配）。
- 在验证假设或衡量干预措施的效果时（如 A/B 测试、实验分析）。
- 在准备报告或向利益相关者传达关键洞察时。

## Process

1. **定义清晰目标**  
   明确分析的目的和要回答的问题。设定具体、可衡量的目标，避免被数据淹没。

2. **收集和选择高质量数据**  
   确保数据来源可靠、完整且与目标相关。检查数据准确性、一致性和时效性。

3. **数据清洗与准备**  
   处理缺失值、重复项、异常值，并标准化数据格式。将数据转换为适合分析的形态（如数据透视表、聚合表）。

4. **数据分析与建模**  
   应用适当的统计方法、机器学习算法或探索性数据分析（EDA）技术。使用可视化工具（如图表、仪表板）辅助理解模式。

5. **解释与沟通结果**  
   将分析结果转化为清晰、可操作的洞察。使用故事叙述和可视化向非技术利益相关者传达关键发现。

6. **持续学习与迭代**  
   根据反馈和新的数据更新分析，保持对最新工具和方法的学习，并记录复盘经验。

## Verification

- **目标对齐检查**：分析结果是否直接回应了最初设定的目标？是否避免了过度推断？
- **数据质量审核**：确认数据清洗步骤是否完整，关键指标是否无误（例如：总数、平均值、分布是否合理）。
- **结果复现性**：由独立人员或使用不同工具/方法重新运行分析，看是否得到一致结果。
- **敏感性分析**：测试关键假设或参数变化对结论的影响程度，评估结果的稳健性。
- **外部验证**：将分析结果与已知基准、历史数据或领域专家的判断进行对比。
- **利益相关者反馈**：确保非技术受众能够理解并信任分析结论，必要时提供补充解释或可视化。
