# database-operations

## Overview

数据库操作是组织数据基础设施的核心，涵盖从部署、配置、监控到优化的全生命周期管理。掌握数据库操作最佳实践能够将数据库从简单的数据存储转化为支持业务增长、保障数据安全、提升应用性能的战略资产。本技能聚焦于现代云环境下的九大关键实践：安全加固、性能调优、可扩展架构设计、备份与恢复规划、内存与存储管理、统计信息收集、作业队列参数配置、访问控制以及Redo日志大小优化。

## When to Use

- 需要部署或重新架构数据库时，确保初始设计遵循最佳实践
- 数据库性能出现瓶颈（如查询缓慢、高延迟）时，进行系统化调优
- 面临安全合规要求，需要加固数据库访问控制和数据加密
- 业务增长导致数据量激增，需要设计可扩展架构（如分片、读写分离）
- 制定灾难恢复计划，确保RPO/RTO达标
- 日常运维中，进行定期的健康检查与统计信息更新

## Process

1. **安全加固**：实施最小权限原则，使用角色和用户分离；启用传输加密（TLS）和静态加密；定期审计访问日志。
2. **性能调优**：分析慢查询日志，优化索引和SQL语句；调整内存参数（如共享池、缓冲池）和I/O配置。
3. **备份与恢复规划**：制定全量+增量备份策略，定期测试还原流程；优化Redo日志大小以避免频繁切换。
4. **可扩展架构**：评估读写负载，设计读写分离（主从复制）或数据分片；规划连接池和缓存层。
5. **作业队列管理**：合理设置job_queue_processes参数，避免作业堆积影响系统资源。
6. **统计信息收集**：定期更新表和索引的统计信息，确保优化器生成高效执行计划。
7. **内存与存储管理**：监控内存使用率，避免PGA或SGA过度分配；根据访问模式选择存储类型（SSD/HDD）。
8. **访问控制**：定义精细的权限粒度（表级、列级），分离DBA与开发账号。
9. **监控与告警**：部署数据库监控工具（如Prometheus + Grafana），设置CPU、内存、连接数、复制延迟等关键指标的告警阈值。

## Verification

- **安全验证**：使用渗透测试工具检查未授权访问漏洞；审计日志中无非法登录尝试。
- **性能验证**：执行基准测试（如TPC-C）对比调优前/后吞吐量；查询响应时间降低≥20%。
- **备份恢复验证**：每月执行一次全量恢复演练，确保数据完整性和RTO达标（如<4小时）。
- **扩展验证**：在模拟增长压力下，读写分离架构能将写性能提升≥1.5倍，读性能提升≥3倍。
- **统计信息有效性**：检查`last_analyzed`时间，确保统计信息新鲜度在合理范围内（如24小时内）。
- **访问控制验证**：用低权限用户尝试越权操作，应被明确拒绝。
