# 时间序列分析

## Overview

时间序列分析是一项关键的统计学工具，涉及对按时间间隔依次收集或记录的数据点进行理解与分析。本技能涵盖了从基础概念（如自相关、偏自相关、平稳性）到数据预处理（差分、变换、季节调整、异常值处理），再到模型选择与估计（ARIMA、指数平滑、最大似然估计、贝叶斯方法），以及诊断测试与验证（残差分析、拟合优度、预测准确性度量）的完整流程。最终应用于经济预测、库存管理、风险评估等实际场景。

## When to Use

- 数据是按固定时间间隔采集的序列（如每日销售额、每小时温度、月度GDP）。
- 目标是发现历史规律（趋势、季节、周期）或预测未来值。
- 需要对预测结果的可靠性进行统计推断（置信区间、假设检验）。
- 场景包括经济预测、库存管理、风险分析、运营监控等。

## Process

1. **数据探索与可视化**：绘制时间序列图，检查趋势、季节性、周期性及异常值。
2. **平稳性检验**：使用ADF检验或KPSS检验等判断序列是否平稳；若不平移进行差分或变换。
3. **数据预处理**：
   - 差分（一阶差分/季节差分）去除趋势和季节性。
   - 对数变换/Box-Cox变换稳定方差。
   - 季节调整（如X-13ARIMA-SEATS）。
   - 处理缺失值与异常值（插值或替换）。
4. **识别模型结构**：
   - 绘制ACF和PACF图，确定ARIMA(p,d,q)或季节性ARIMA(P,D,Q,s)的阶数。
   - 或考虑指数平滑模型（Holt-Winters等）。
5. **模型估计与选择**：
   - 使用最大似然估计拟合ARIMA/指数平滑模型。
   - 可尝试贝叶斯方法（MCMC）建模先验分布和后验推断。
   - 比较AIC/BIC等信息准则或多步时序交叉验证。
6. **诊断检查**：
   - 残差分析：检验残差是否为白噪声（Ljung-Box检验），检查残差是否正态且无显著自相关。
   - 评估拟合优度（R²、调整R²等）。
7. **预测与验证**：
   - 使用选定模型生成未来值及预测区间。
   - 采用留出集或时序交叉验证评估预测准确性，常用指标包括MAE、RMSE、MAPE、MASE等。
8. **部署与监控**：将模型投入生产，持续收集新数据并定期重新训练。

## Verification

- **平稳性验证**：差分后的序列通过ADF检验（p<0.05）或KPSS检验不能拒绝平稳性原假设。
- **残差白噪声**：Ljung-Box检验的p值>0.05，且残差ACF图中无明显滞后显著。
- **预测准确度**：在测试集上计算MAE/MSE/RMSE/MAPE/MASE，并与基线（如naive、季节naive）比较。
- **模型稳定性**：使用滚动原点验证或时序交叉验证，确保不同时间段性能一致。
- **逻辑合理性**：预测值在合理范围内，置信区间不过宽，无趋势偏离业务常识。
- **代码复现**：所有步骤需记录种子、参数和版本，确保他人可复现结果。
